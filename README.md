## Descripción del proyecto

El presente repositorio tiene como objetivo evidenciar el proceso de instalación, configuración y utilización de Git como herramienta de control de versiones, junto con GitHub para la administración de repositorios remotos.

## Herramientas utilizadas

- Git
- GitHub
- Visual Studio Code

## Procedimientos realizados

1. Instalación de Git.
2. Configuración del nombre y correo electrónico.
3. Creación de un repositorio público en GitHub.
4. Inicialización del repositorio local.
5. Vinculación del repositorio local con GitHub.
6. Verificación de los repositorios remotos.
